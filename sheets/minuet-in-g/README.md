# Minuet in G major (BWV Anh. 114): key by key

Christian Petzold, from the Notebook for Anna Magdalena Bach. For the MPK mini's 25 keys (C2–C4, the MPK on OCT 0), exactly the keys SS Studio's Learn mode shows.

How to read it:

- Each line is one bar of 3 counts. `R` is the right hand, `L` the left hand.
- Each note is `key (when, how long)`: `D3 (1, 1)` means press D3 on count 1 and hold it for 1 count. `1&` is halfway between counts 1 and 2.
- `+` joins keys pressed together. `*` marks a key the other hand also plays at that moment: with both hands, press it once.
- Play Part A (bars 1–16) twice, then Part B (bars 17–32) twice.

Notes from the Mutopia Project edition (public domain), with the right hand one octave down and five notes moved by an octave so everything fits on 25 keys.
